# Profil par défaut Tunet

Copier ici un export Tunet sous le nom `maison.json`.

Le fichier est lu au premier accès d'un navigateur qui ne possède pas encore
`tunet_pages_config`. Les personnalisations locales ultérieures ne sont jamais
écrasées automatiquement.

Ne jamais placer de jeton Home Assistant, mot de passe, cookie Authelia ou clé
API dans ce fichier.
